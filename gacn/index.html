03 / 科学依据

实际求解的是什么

几何。取 rs = 1，故 M = ½。事件视界在 r = 1，光子球在 r = 1.5，ISCO 在 r = 3，临界碰撞参数为 bc = 3√3 / 2 = 2.5981 rs。史瓦西黑洞自旋为零。

积分。光线遵循 d²r/dλ² = −(3/2) h² r / r⁵，其中 h = |r × dr/dλ| 守恒。每条相机光线以自适应经典 RK4 积分，直至穿越视界、逃逸或用尽 520 步。每个初始方向都施加有限半径静态观测者修正。

辐射转移。每次赤道面穿越都用三次 Hermite 求根，并采样相对论黑体。局部开普勒速度为 β = √(M / (r − 2M))；观测温度为 Tobs = gTem，其中 g = √(1 − rs/r) / [γ(1 − β·n)]。亮度采用总辐射 g⁴ 转移。多次穿越构建直接、二次与高阶盘像。

呈现。HDR 辐亮度存入 RGBA16F，经阈值化多尺度泛光与 ACES 色调映射，再以横向色散、暗角、胶片颗粒和极少量抖动收束，使虚空保持纯净。
