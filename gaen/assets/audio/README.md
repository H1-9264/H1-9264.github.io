# Ambient Horizon

`ambient-horizon.ogg` is an original procedural composition generated in-repo from synthesized oscillators, filtered periodic noise, and soft modal resonances. It contains no sampled or downloaded audio.

- Format: Ogg Vorbis, 48 kHz, stereo
- Loop duration: 75.000 s = 25 bars of 4/4 at 80 BPM
- Harmony: D-minor pedal centered on D1/A1/D2/F2/A2 in just intonation; every sustained partial and modulation LFO completes an integer number of cycles in the loop
- Texture: slowly detuned low drone, evolving filtered "solar wind", sparse distant metallic resonances, and a soft heartbeat-like sub pulse every 5 bars
- Loop design: no fade in or fade out is baked in; the final sample leads continuously into the first
- Loudness: -20.0 LUFS integrated; -6.4 dBFS true peak
- Size: 792,697 bytes (about 0.76 MiB)
- Loop check: decoded first/last 0.25 s RMS is -16.97 / -16.56 dBFS (0.41 dB difference); the seam step is within the normal adjacent-sample range
