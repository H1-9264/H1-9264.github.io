03 / SCIENTIFIC BASIS

What is actually being solved

Geometry. Units are rs = 1, so M = ½. The event horizon is at r = 1, the photon sphere at r = 1.5, the ISCO at r = 3, and the critical impact parameter at bc = 3√3 / 2 = 2.5981 rs. Schwarzschild has zero spin.

Integration. Light rays obey d²r/dλ² = −(3/2) h² r / r⁵, with conserved h = |r × dr/dλ|. Each camera ray is integrated with adaptive classical RK4 until it crosses the horizon, escapes, or exhausts 520 steps. The finite-radius static observer correction is applied to every initial direction.

Radiative transfer. Each equatorial plane crossing is solved with a cubic Hermite root and sampled for a relativistic blackbody. The local Keplerian speed is β = √(M / (r − 2M)); observed temperature is Tobs = gTem, with g = √(1 − rs/r) / [γ(1 − β·n)]. Brightness uses the bolometric g⁴ transfer. Multiple crossings build the direct, secondary and higher-order disk images.

Presentation. The HDR radiance is stored in RGBA16F, bloomed through a thresholded multi-scale chain, tone-mapped with ACES, then finished with lateral dispersion, vignette, grain and the smallest amount of dither needed to keep the void clean.
