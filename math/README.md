# Buzhidao Math · 数学可视化实验室

> 一个**纯前端、零依赖、离线可用**的数学工作台：函数绘图器 + 几何画板 + 实用小工具。
> 深色优先的界面、极高的可自定义程度、支持导出高清图像。

```
函数绘图    几何画板    实用工具
 ├ 多曲线     ├ 尺规作图    ├ 导数探索器
 ├ 参数方程   ├ 动态依赖    ├ 数据绘图
 ├ 极坐标     ├ 变换        ├ 单位换算
 ├ 求根/交点  ├ 测量        ├ 科学计算器
 └ 定积分     └ 轨迹        ├ 调色板 / 番茄钟
```

## 1. 快速开始

### Windows（推荐）
双击 **`start.bat`** —— 脚本会自动寻找 Python 或 PowerShell，在 `http://127.0.0.1:8000` 启动本地静态服务器并打开浏览器。

```bat
start.bat            :: 默认 8000 端口
start.bat 8123       :: 指定端口
```

### 其他方式
```bash
# 任意静态服务器都可以
python -m http.server 8000
npx serve .
```

> ⚠️ 项目使用 ES Module（`<script type="module">`）。直接用 `file://` 双击打开会被浏览器的
> CORS 策略拦截，**请务必通过本地服务器访问**（或部署到 GitHub Pages 等静态托管）。

## 3. 函数绘图器

| 能力 | 说明 |
| --- | --- |
| 曲线模式 | 直角坐标 `y=f(x)`、参数方程 `(x(t), y(t))`、极坐标 `r=f(θ)`、数据点 |
| 多曲线 | 任意条数，独立颜色/线宽/可见性，可拖拽排序；**默认空白画板**，✨ 一键载入示例 |
| 单条范围 | 每条曲线可单独设置 `x ∈ [ ]`、`y ∈ [ ]` 显示范围（留空 = 跟随全局），🎯 按钮按该曲线自适应 |
| 等比例 | 每条曲线可勾选 **1:1 等比例**，视图自动按曲线内容撑开，几何图形不再被拉伸 |
| 交互 | 滚轮缩放、拖拽平移、双击复位、适应内容、等比例坐标 |
| 跟踪 | 鼠标实时读数，点击固定；可叠加切线并显示 f′(x) |
| 分析 | 数值求零点、求交点、极值点，定积分填充与数值结果 |
| 变量 | 表达式里写 `a`、`b`、`k` 自动生成滑杆，实时联动 |
| 导出 | PNG(1x/2x/3x/4x/6x 印刷 + **正方形 1080 / 宽屏 1920×1080 / 课件 1600×900** 三种画布预设，可选白底/深底/透明)、SVG 矢量、CSV 数据、JSON 工程、**讲义图**（图 + 表达式清单；**标题可自定义或留空**，不会写入应用名） |
| 分享 | 一键把当前函数与视图编码进链接（`#s=...`），发给别人打开就是同一张图 |

表达式引擎支持：

- 运算符：`+ - * / ^`、隐式乘法（`2x`、`3sin(x)`、`(x+1)(x-1)`）、比较与条件 `? :`、后缀阶乘 `!`
- 函数：`sin cos tan asin acos atan atan2 sinh cosh tanh asinh acosh atanh ln log log2 log10 exp sqrt cbrt abs sign floor ceil round trunc min max pow mod hypot clamp step sinc gamma fact nthroot random degrees radians`
- 常数：`pi`、`e`、`tau`、`phi`、`inf`

## 4. 几何画板（参考几何画板的逻辑）

- **默认空白画板**：打开即是干净画布，空状态里有「载入示例」和「开始时画点」两个引导按钮。
- **依赖图**：每个对象记录父对象，按拓扑序重算；拖动一个自由点，所有派生对象（中点、垂线、交点、变换图形、测量值…）自动跟进。
- **工具分组**：基础（选择/点/轨迹）、线（线段/直线/射线/向量）、圆（圆心+点 / 过三点 / 定半径 / 三点弧）、构造（中点/垂线/平行线/中垂线/角平分线/交点/多边形/区域）、测量（长度/角度/面积/斜率/半径/坐标）、变换（平移/旋转/反射/位似缩放）、其他（文本标注/删除）。
- **吸附**：靠近已有点自动吸附；落在直线或圆上会「粘」在该对象上并保持约束。
- **轨迹**：开启轨迹追踪后拖动某点即可留下轨迹（虚线）。
- **示例**：工具栏 ✨ 一键生成「三角形 + 三条高 + 外心 + 外接圆 + 测量」。
- **交互细节**：提示气泡跟随鼠标并自动上下翻转（不会被浏览器标签栏挡住），展开面板会自动滚入视野，
  定半径圆 / 缩放比例 / 文本标注使用自定义弹窗（不再用浏览器原生 `prompt`）。
- **导出**：PNG(2x)、SVG 矢量、JSON 工程（可再次导入），内容自动保存到本地。

## 9. 实现约定（踩过的坑）

- **画布尺寸**：所有 canvas 的**后备分辨率必须等于 CSS 显示尺寸**。容器高度由 CSS 决定
  （`.chart-card { height: clamp(300px, 46vh, 460px) }`），JS 用 `measureHost()` 实测容器后
  同时设置 `canvas.width/height` 与 `canvas.style.width/height`。**不要用 vh 去钳制 canvas 自身高度**，
  否则会出现"测量 → 撑大 → 再测量"的正反馈，导致图像莫名拉长变形。
- **整屏应用页**：绘图器与几何画板会自动给 `<body>` 加 `is-app` 类，隐藏页脚并把
  `.app-shell` 固定为 `calc(100dvh - var(--nav-h))`，从而消除页面级滚动 —— 否则侧栏最后一块面板会被推到视口之外。
- **语言字典拆分**：文案分别放在 `assets/js/core/lang-zh.js` / `lang-en.js` / `lang-ja.js`，
  `i18n.js` 只保留逻辑。这样每个文件都远小于写入上限，也方便单独校对某一语言。
- **大文件写入**：单个 JS 文件超过约 16KB 时，整文件重写有被截断的风险；本项目的大字典/长模块
  都拆成多次追加写入，并用 `node --check` 自检。
- **比例自适应**：绘图器在 `render()` 里检查画布宽高比，若与视图范围不一致，
  就按"基准范围"向外扩展成等比（x/y 单位长度一致）——否则竖屏手机上圆会变椭圆、
  曲线看着像被拉长。用户手动改过范围（`userRange`）或勾了 1:1 就不再干预。
- **导出画布**：`buildExportCanvas()` 渲染导出图时**必须把 `engine.dpr` 设成 1**，
  否则 render() 里的 ctx 变换会按屏幕 dpr 再放大一次，导出图被裁切放大（只剩左上角一小块）。
  另外讲义图按"视图范围的比例"出图，保证导出图里 x/y 单位也一致。
- **滚动容器**：`.app-side-scroll` / `.drawer-body` / `.card-body` 里的子项必须 `flex: 0 0 auto`，
  否则内容变多（例如函数列表变长）时下面的面板会被 flex 压成一条线。

## 10. 函数分析工具（可自选函数）

分析面板不再固定分析"第一条曲线"，而是可以**任选一条函数**（下拉框自动跟随函数列表刷新），
并支持自定义分析区间（或一键同步为当前视图范围）：

| 功能 | 说明 |
| --- | --- |
| 零点 | 网格扫符号变化 + 二分细化；自动识别端点零点，跳过 `1/x` 这类间断点 |
| 极值点 | 一阶差分变号 + 黄金分割细化，区分极大/极小并给出 f'(x) |
| 拐点 | 二阶差分变号 + 二分细化，附凹凸性 |
| 单调 / 凹凸 | 把区间切成"递增递减 × 凹/凸"的段落（断点处自动断开） |
| 交点 | 任选**两条**曲线求交，结果校验 f−g ≈ 0 |
| 全面分析 | 概览（最值/均值/f(0)/零点数/连续性）+ 积分 + 平均值 + 弧长 + 各表 |
| 定积分对比 | Simpson 精确值 vs 黎曼和（左/右/中点，n 可调）与误差 |
| 数据表 | x / f(x) / f'(x) / f''(x) 四列 |
| 按点拟合 | 输入若干点坐标，自动在 10 种模型里挑最好的（R²、RMSE、残差表），可一键画到画布 |
| 结果导出 | 复制到剪贴板 / 导出 CSV |

拟合支持模型：一次、二次、三次、四次、五次、六次多项式、幂函数 `a·x^b`、指数 `a·e^(bx)`、
对数 `a+b·ln(x)`，以及"自动挑选"（R² 相差 1% 以内时优先选更简单的模型，避免过拟合）。
点坐标解析很宽松：`1,2` / `1 2` / `(1, 2)` / `x=1 y=2` 都行，一行可以写多对。

数值分析的核心在 `assets/js/plot/analyze.js`，拟合在 `assets/js/plot/fit.js`，
单元测试在 `tools/test-analyze.mjs`（33 项，`node tools/test-analyze.mjs`）。

## 11. 这一轮新增（灵感 2–5）

- **撤销 / 重做**：绘图器支持 `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`），工具栏也有按钮。
  表达式输入按 600ms 合并成一步，拖拽排序、增删曲线、切换网格、改范围都会进历史（最多 60 步）。
- **移动端手势**：绘图器与几何画板都支持**双指捏合缩放 + 双指拖动平移**（单指仍是拖动/选择）。
- **PDF 讲义**：自研极简 PDF 写入器 `assets/js/plot/pdf.js`（零依赖，JPEG 嵌入 + 多页 + 文本/XObject），
  `导出 PDF 讲义` 会生成 A4 多页：第 1 页是图表 + 表达式清单，后面 2 页是采样数据表。
- **作图回放**：几何画板的 `▶` 按钮打开回放面板，滑块/播放键逐步重演整幅图的构造过程
  （每个对象记录 `createdAt` 序号，对象列表与测量结果会跟着步骤显现）。
