# Buzhidao Math · 数学可视化实验室

> 一个**纯前端、零依赖、离线可用**的数学工作台：函数绘图器 + 几何画板 + 实用小工具。
> 深色优先的界面、极高的可自定义程度、支持导出高清图像。

```
函数绘图    几何画板    实用工具
 ├ 多曲线     ├ 尺规作图    ├ 导数探索器
 ├ 参数方程   ├ 动态依赖    ├ 数据绘图
 ├ 极坐标     ├ 变换        ├ 单位换算
 ├ 求根/交点  ├ 测量        ├ 科学计算器
 └ 定积分     └ 轨迹        ├ 调色板 / 番茄钟
```

## 1. 快速开始

### Windows（推荐）
双击 **`start.bat`** —— 脚本会自动寻找 Python 或 PowerShell，在 `http://127.0.0.1:8000` 启动本地静态服务器并打开浏览器。

```bat
start.bat            :: 默认 8000 端口
start.bat 8123       :: 指定端口
```

### 其他方式
```bash
# 任意静态服务器都可以
python -m http.server 8000
npx serve .
```

> ⚠️ 项目使用 ES Module（`<script type="module">`）。直接用 `file://` 双击打开会被浏览器的
> CORS 策略拦截，**请务必通过本地服务器访问**（或部署到 GitHub Pages 等静态托管）。

## 3. 函数绘图器

| 能力 | 说明 |
| --- | --- |
| 曲线模式 | 直角坐标 `y=f(x)`、参数方程 `(x(t), y(t))`、极坐标 `r=f(θ)`、数据点 |
| 多曲线 | 任意条数，独立颜色/线宽/可见性，可拖拽排序；**默认空白画板**，✨ 一键载入示例 |
| 单条范围 | 每条曲线可单独设置 `x ∈ [ ]`、`y ∈ [ ]` 显示范围（留空 = 跟随全局），🎯 按钮按该曲线自适应 |
| 等比例 | 每条曲线可勾选 **1:1 等比例**，视图自动按曲线内容撑开，几何图形不再被拉伸 |
| 交互 | 滚轮缩放、拖拽平移、双击复位、适应内容、等比例坐标 |
| 跟踪 | 鼠标实时读数，点击固定；可叠加切线并显示 f′(x) |
| 分析 | 数值求零点、求交点、极值点，定积分填充与数值结果 |
| 变量 | 表达式里写 `a`、`b`、`k` 自动生成滑杆，实时联动 |
| 导出 | PNG(1x–4x，可选白底/深底/透明)、SVG 矢量、CSV 数据、JSON 工程 |

表达式引擎支持：

- 运算符：`+ - * / ^`、隐式乘法（`2x`、`3sin(x)`、`(x+1)(x-1)`）、比较与条件 `? :`、后缀阶乘 `!`
- 函数：`sin cos tan asin acos atan atan2 sinh cosh tanh asinh acosh atanh ln log log2 log10 exp sqrt cbrt abs sign floor ceil round trunc min max pow mod hypot clamp step sinc gamma fact nthroot random degrees radians`
- 常数：`pi`、`e`、`tau`、`phi`、`inf`

## 4. 几何画板（参考几何画板的逻辑）

- **默认空白画板**：打开即是干净画布，空状态里有「载入示例」和「开始时画点」两个引导按钮。
- **依赖图**：每个对象记录父对象，按拓扑序重算；拖动一个自由点，所有派生对象（中点、垂线、交点、变换图形、测量值…）自动跟进。
- **工具分组**：基础（选择/点/轨迹）、线（线段/直线/射线/向量）、圆（圆心+点 / 过三点 / 定半径 / 三点弧）、构造（中点/垂线/平行线/中垂线/角平分线/交点/多边形/区域）、测量（长度/角度/面积/斜率/半径/坐标）、变换（平移/旋转/反射/位似缩放）、其他（文本标注/删除）。
- **吸附**：靠近已有点自动吸附；落在直线或圆上会「粘」在该对象上并保持约束。
- **轨迹**：开启轨迹追踪后拖动某点即可留下轨迹（虚线）。
- **示例**：工具栏 ✨ 一键生成「三角形 + 三条高 + 外心 + 外接圆 + 测量」。
- **交互细节**：提示气泡跟随鼠标并自动上下翻转（不会被浏览器标签栏挡住），展开面板会自动滚入视野，
  定半径圆 / 缩放比例 / 文本标注使用自定义弹窗（不再用浏览器原生 `prompt`）。
- **导出**：PNG(2x)、SVG 矢量、JSON 工程（可再次导入），内容自动保存到本地。

## 6. 自定义与主题

打开右上角 ⚙ 或按 `Ctrl + ,`：

- 显示模式：深色 / 浅色 / 跟随系统
- 10 套预设配色：**GitHub 绿（默认）**、琥珀黄、青柠、深林、余烬、青碧、石墨灰、纯黑 OLED、白昼
- 强调色自由取色，一键「从主色生成整站配色」（自动推导背景与辅助色）
- 字体（无衬线/衬线/等宽）、字号缩放、圆角、毛玻璃强度、动画开关、发光效果
- 语言：简体中文 / English / 日本語
- 设置导出/导入（JSON）、一键恢复默认

所有设置保存在浏览器 `localStorage`（键名前缀 `bzm:`），不上传任何数据。

## 7. 部署到 GitHub Pages

1. 把整个文件夹推送到仓库（`main` 分支）。
2. 仓库 **Settings → Pages → Source: Deploy from a branch**，选择 `main` / `/ (root)`。
3. 访问 `https://<用户名>.github.io/<仓库名>/` 即可。

项目全部使用**相对路径**，放在子目录（如 `/math/`）下也能正常工作。

## 8. 开发说明

- **零依赖**：没有 npm 包、没有构建步骤、没有 CDN，全部是原生 HTML / CSS / ES Module。
- **离线可用**：断网后所有功能照常工作。
- **自动测试**（需要本机有 Chrome/Edge，可选）：

```bash
node tools/test-engine.mjs                      # 引擎逻辑（解析器/绘图/几何/工具）
node tools/smoke.mjs http://127.0.0.1:8000 --shots
node tools/smoke.mjs http://127.0.0.1:8000 --page=tools.html#calc
node tools/shoot.mjs http://127.0.0.1:8000/plotter.html out.png 4000 seed.js
```

会逐个打开页面、收集控制台错误/异常、并可选输出截图到 `.shots/`。
