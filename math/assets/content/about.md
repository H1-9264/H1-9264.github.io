# 关于 Buzhidao Math

> 一个**纯前端、零依赖、离线可用**的数学工作台：函数绘图器 + 几何画板 + 实用小工具。
> 所有计算都在你的浏览器里完成，不上传任何数据，断网也能用。

---

## 这是什么

Buzhidao Math 想解决的问题很简单：**把数学画出来，比讲十遍更清楚。**

它不是一个在线服务，而是几个装在文件夹里的普通网页 —— 双击就能跑，拷到 U 盘里带到教室也能跑。
没有构建步骤、没有 npm 依赖、没有 CDN 请求，整个项目的体积比一张手机照片还小。

| 模块 | 一句话说明 | 入口 |
| --- | --- | --- |
| 函数绘图器 | 多曲线、参数方程、极坐标，求根求交点求积分，导出高清图 | `plotter.html` |
| 几何画板 | 尺规作图式动态几何，拖动一点全图联动 | `geometry.html` |
| 实用工具 | 导数探索、数据绘图、单位换算、计算器、调色板、番茄钟 | `tools.html` |
| 帮助文档 | 表达式语法、操作指南、快捷键 | `help.html` |

## 主要特性

- **表达式引擎**是自研的：词法分析 → 语法树 → 编译成闭包，支持隐式乘法（`2x`、`3sin(x)`、`(x+1)(x-1)`）、
  条件表达式、后缀阶乘、40 多个数学函数，全程不用 `eval`。
- **绘图引擎**自适应刻度、自动断开渐近线、按像素采样，还能导出 SVG 矢量图。
- **几何画板**用依赖图 + 拓扑排序重算：每个对象记住自己的父对象，
  拖一个自由点，中点、垂线、交点、变换图形、测量值会一起更新。
- **高度自定义**：10 套配色、强调色自由取色、字体/字号/圆角/毛玻璃/动画开关，设置保存在本地。
- **多语言**：简体中文 / English / 日本語 一键切换。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl` + `K` | 命令面板（搜功能、工具、页面） |
| `Ctrl` + `,` | 打开设置 |
| `Ctrl` + `S` | 导出当前图像 |
| `G` / `R` / `F` | 网格 / 复位视图 / 适应内容 |
| `Ctrl` + `Z` | 撤销（几何画板） |
| `?` | 显示全部快捷键 |

## 技术栈

```
HTML5 + CSS（自定义属性做主题令牌）
ES Module（原生模块，无打包器）
Canvas 2D（绘图与几何渲染）
localStorage（设置与作品保存）
```

## 本地运行

```bat
:: Windows：双击即可，脚本会自动找 Python 或 PowerShell
start.bat

:: 或者任意静态服务器
python -m http.server 8000
```

> ⚠️ 项目使用 ES Module，直接双击 `.html` 可能被浏览器的 CORS 策略拦截，请通过本地服务器访问。

## 部署到 GitHub Pages

1. 把整个文件夹推送到仓库
2. **Settings → Pages → Source: Deploy from a branch**，选 `main` / `/ (root)`
3. 访问 `https://<用户名>.github.io/<仓库名>/`
